### Class 1: Hex World & Terrain Primitives

#### 1. Pointy-Topped Hexagonal Column (`HexTile_{q}_{r}`)
- **Node Type:** `MeshInstance3D`
- **Parent:** `HexGrid` (`Node3D`)
- **Mesh:** `CylinderMesh` ($R = 1.5\text{m}$, $H = 0.4\text{m}$, 6 radial segments).
- **Transform:**
  $$X = R \sqrt{3} \left( q + \frac{r}{2} \right), \quad Y = 0.0, \quad Z = R \frac{3}{2} r$$
- **Biome Material Overrides:**
  - *North Quadrant ($q \ge 0, r \ge 0$):* `crystal_facet_pbr` (Ice-blue crystalline plate).
  - *West Quadrant ($q < 0$):* `toxic_slime_organic` (Viscous neon-green acid pool).
  - *South Quadrant ($r < 0$):* `druid_ancient_bark` (Mossy fertile loam).
  - *Center Citadel ($q=0, r=0$):* `basalt_fortress_stone` (Basalt fortress slab).

#### 2. Fortification Barrier Ring (`FortificationRing_{sector}`)
- **Node Type:** `MeshInstance3D`
- **Mesh:** `TorusMesh` ($R_{\text{inner}} = 1.6\text{m}$, $R_{\text{outer}} = 1.75\text{m}$, 6 segments).
- **Material:** Emissive pulse material colored by contest status:
  - `UNCONTESTED`: Steady Cyan (`#66fcf1`) glow ($1.0\times$).
  - `UNDER_SIEGE`: Rapid pulsing Crimson (`#ff453a`) glow ($2.5\times$).
  - `CAPTURED`: Flash white-to-owner transition.

## 4. Sub-Resource Godot 4 .TSCN Serialization Syntax

To ensure seamless import by Godot 4 without external `.tres` files, scenes are serialized with inline `[sub_resource]` headers:

```ini
[gd_scene format=3 uid="uid://krystal_posledni_kmen"]

# 1. Sub-Resources: PBR Materials & Primitive Meshes
[sub_resource type="StandardMaterial3D" id="StandardMaterial3D_cryst"]
albedo_color = Color(0.4, 0.98, 0.94, 0.85)
metallic = 0.85
roughness = 0.15
emission_enabled = true
emission = Color(0, 1, 1, 1)
emission_energy_multiplier = 2.4
subsurface_scattering_enabled = true
transparency = 1

[sub_resource type="CylinderMesh" id="CylinderMesh_hex"]
top_radius = 1.5
bottom_radius = 1.5
height = 0.4
radial_segments = 6

# 2. Node Hierarchy
[node name="TacticalArena" type="Node3D"]

[node name="Hex_0_0" type="MeshInstance3D" parent="."]
transform = Transform3D(1, 0, 0, 0, 1, 0, 0, 0, 1, 0, 0, 0)
mesh = SubResource("CylinderMesh_hex")
surface_material_override/0 = SubResource("StandardMaterial3D_cryst")
```

## 5. GPU Instancing & MultiMeshInstance3D Optimization

When rendering large tactical battlefields ($> 64$ hexes):
- Individual `MeshInstance3D` nodes are batched into a single `MultiMeshInstance3D`.
- **Instance Transform Buffer:** Stored in a flat 12-float array per hex.
- **Custom Data Buffer:** 4 floats per hex storing `(q, r, BiomeID, FortificationHP)`.
- **Draw Call Reduction:** Reduces draw calls from $N$ to $1$, sustaining $120\,\text{FPS}$ on mobile and integrated GPUs (e.g. Intel Iris Xe / Vulkan).
