## 2. Research Questions Summary

1. **Hlavná výskumná otázka:**
   *„Dokáže súčasný Cascade Planner prejsť zo statickej estimácie na closed-loop plánovanie len z dát, ktoré už produkuje?“*
   - **Verdikt:** **ÁNO.** `CascadeExecutionTrace` a `ClosedLoopCascadeFeedback` už dnes produkujú skutočné `latency_ms`, `error_lat_ms` a `regret`. Stačí prepojiť tieto výstupy do `CascadePlanner.estimate_latency()` namiesto statických konštánt.
2. **Subsidiárna výskumná otázka:**
   *„Je už Model Node dostatočný task primitive pre LLM, alebo len execute primitive?“*
   - **Verdikt:** **NIE, je to len EXECUTE PRIMITIVE.** Chýbajú mu stavy životného cyklu (`QUEUED`, `SCHEDULED`, `COMMITTED`, `REJECTED`), priority a zmluvy o časovom rozpočte (SLO deadlines).
